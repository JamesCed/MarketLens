Google Places API
0 = unlimited (recommended) — the app keeps paging until Google runs out of results, so a barangay's business count reflects what is really there instead of stopping at the first page. Note that Google itself caps Text Search at 60 results per query (20 per page, 3 pages), so a count sitting at exactly 60 means "60 or more". API keys themselves are set in the .env file, not here (see README).
AI-Generated Recommendation Text
When off (default), the built-in rule-based text generator is used — no API key needed. When on, the provider set by LLM_PROVIDER in .env (openai by default, or anthropic) writes the text using OPENAI_API_KEY or ANTHROPIC_API_KEY respectively — set in the .env file, not here (see README). If that key is missing, the other provider's key is tried automatically; if neither is set, this falls back to the rule-based text with no error.

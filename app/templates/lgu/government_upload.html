Important Guidelines:
  • Gov't / Zoning Data (lgu_data) needs a barangay column, plus any of zoning_info, closure_records, permit_count, business_density, effective_date.
  • Market Data (market_data) needs industry_type, location columns, plus any of competitor_count, population_density, historical_success_rate, foot_traffic_index, average_rent, date_recorded.
  • Missing numeric values in columns you DO include are automatically filled in using that column's average (data imputation).
  • The uploaded file itself is not stored -- only the parsed data rows are saved.
